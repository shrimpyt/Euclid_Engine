I. Definitions — copy each one exactly

Quadratic function
A function that can be written f(x) = ax² + bx + c, where a ≠ 0.
Vertex form
f(x) = a(x − h)² + k. The vertex is visible directly: (h, k).
Vertex
The highest or lowest point of the parabola.
Axis of symmetry
The vertical line x = h, across which the parabola mirrors itself.

II. Demonstration — supply the reason for each step

Describe the transformations of g(x) = −2(x − 3)² + 1 compared to the parent function y = x². State the vertex and the axis of symmetry.

  1. In vertex form a(x − h)² + k:  a = −2,  h = 3,  k = 1.

III. Questions for Discussion

1. Why does (x − 3) shift the graph right when 3 is being subtracted?

2. How does the single value a control both the width and the direction of the parabola?

3. What would change — and what would stay the same — if a were −½ instead of −2?
